**Rhinestone is self-custodial stablecoin infrastructure for fintechs.** Wallets,
deposits, relaying and fiat integrations, all under one SLA.

We co-authored and led [ERC-7579](https://erc7579.com), the modular smart account
standard, and built its [reference implementation](https://github.com/erc7579/erc7579-implementation).
